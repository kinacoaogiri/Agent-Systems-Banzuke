# Rubric

## Governing purpose: Human Capability Impact

> **人間の行為にどれだけ有益か**
>
> **How much does the system materially expand or improve human action?**

Human Capability Impact may be realized through **Augmentation** or **Delegation / Substitution**. Novelty and architecture are means/evidence, not independent scoring purposes.

Each domain has a Capability Level and Evidence Level:

`Recognized Level_i = min(Capability Level_i, Evidence Level_i)`

`Total Score = sum(Recognized Level_i)`

Maximum: **25**.

## 1. Capability Expansion — 能力拡張

| Level | Definition |
|---|---|
| 0 — None | Human feasible action is not materially expanded. |
| 1 — Assistance | Existing human action becomes easier or faster. |
| 2 — Extension | Scale, speed, or volume burdensome for a human becomes practical. |
| 3 — New Capability | Activity practically difficult for a human alone becomes feasible. |
| 4 — Structural Expansion | Work previously requiring multiple people, specialist organization, or substantial resources becomes feasible with materially less human staffing or coordination. |
| 5 — Transformative Expansion | The practical boundary of human action changes enough to enable a new sustained mode of activity. |

## 2. Delegation Depth — 委任深度

| Level | Definition |
|---|---|
| 0 — Tool | Human remains the executing principal; system is a tool. |
| 1 — Action | A single concrete action can be delegated. |
| 2 — Task | A task with objective and completion condition can be delegated. |
| 3 — Workflow | A coherent multi-task workflow can be delegated. |
| 4 — Role | Continuing responsibility and judgment within a defined role can be delegated. |
| 5 — Role Substitution | Within a defined responsibility scope, the system can practically substitute for execution by a Human Role Holder without human step-by-step performance. |

Legal or ultimate accountability may remain human.

## 3. Autonomy — 自律性

| Level | Definition |
|---|---|
| 0 — Operated | Human instruction is required for each material action. |
| 1 — Local | A narrow specified action executes autonomously internally. |
| 2 — Task | System selects and executes means through task completion. |
| 3 — Workflow | System manages multiple tasks and ordinary branches/failures. |
| 4 — Role | System manages priorities, methods and progress within ongoing responsibility, escalating exceptional cases. |
| 5 — Sustained | System sustains responsibility across time/changing conditions, maintains or recovers state, and limits human intervention to appropriate boundaries. |

Delegation asks **what is entrusted**. Autonomy asks **how independently it proceeds after entrustment**.

## 4. Reliability — 遂行信頼性

| Level | Definition |
|---|---|
| 0 — Unreliable | Work outcomes cannot reasonably be expected. |
| 1 — Demonstrable | Successful examples exist; stable repeatability is not established. |
| 2 — Repeatable | Requirements are repeatedly met under defined routine conditions. |
| 3 — Operational | System can be used continuously under ordinary conditions and handles common failures. |
| 4 — Dependable | High execution stability is evidenced across repetition, duration and exceptions, including failure detection/recovery. |
| 5 — Role-grade | Public evidence establishes continuity, quality and failure handling sufficient to entrust the relevant human-role-level responsibility in practice. |

## 5. Human Control — 人間統制可能性

| Level | Definition |
|---|---|
| 0 — Uncontrolled | Humans cannot adequately understand/control system action, authority or state. |
| 1 — Intervention | Humans can start, stop or directly intervene. |
| 2 — Bounded | Authority, targets, execution scope or comparable boundaries can be defined in advance. |
| 3 — Observable | State, decisions and execution are observable; humans can approve, reject or correct at material points. |
| 4 — Governed | Authority, gates, escalation and auditability are systematic while autonomy remains under Human governance. |
| 5 — Delegated Governance | Without continuous supervision, system maintains authority boundaries and returns deviation, uncertainty or material exceptions to appropriate Human Authority. |

Level 5 moves the Human from continuous operator toward **Authority Holder**. It does not make Human Authority unnecessary.

## Rank qualification

All conditions use recognized levels after Evidence Gate application.

| Rank | Minimum total | Mandatory conditions |
|---|---:|---|
| Maegashira | 5 | At least one domain >= 2 |
| Komusubi | 10 | Delegation >= 2; Reliability >= 2 |
| Sekiwake | 14 | Delegation >= 3; Autonomy >= 3; Reliability >= 3; Human Control >= 2 |
| Ozeki | 18 | Delegation >= 4 **or** Capability Expansion >= 4; Reliability >= 4; Human Control >= 3 |
| Yokozuna | 22 | Delegation = 5 **or** Capability Expansion = 5; Autonomy >= 4; Reliability = 5; Human Control >= 4 |

A system receives the highest rank for which both total threshold and every mandatory condition are satisfied.

## Yokozuna principle

A Yokozuna may reach the highest level through practical Human Role Holder substitution **or** equivalent/great transformative augmentation.

> **強大なCapabilityを持ちながら、その力をHuman Authorityの下で適切に行使できること**

> **強くなければ横綱になれない。強いだけでも横綱になれない。**

Yokozuna may be vacant.
