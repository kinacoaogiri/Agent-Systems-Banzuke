# Rikishi Assessment Records

This directory contains per-system assessment records.

A record should identify the assessed system rather than merely a company or base model, and should include:

- system name and canonical public links;
- division eligibility and human-principal basis;
- evaluated version/commit and evidence cutoff;
- relevant related repositories;
- Capability / Evidence / Recognized level for all five domains;
- supporting and contrary evidence;
- independent reviewer findings;
- Human adjudication;
- total score and highest qualified rank;
- Torikumi references where applicable;
- later Monoii, Retrospective Findings, and Corrections.

Do not overwrite historical findings to make a current assessment look cleaner. Preserve the record of what was known and decided at each Basho.
